# HobFarm

HobFarm is an online magazine and visual studio for original characters, visual stories, production experiments, and creative workflows.

[Visit hob.farm](https://hob.farm)

## Explore

- [Articles](https://hob.farm/articles/) collect features, essays, research, satire, and production notes.
- [Gallery](https://hob.farm/gallery/) is the visual archive for character sheets, image sets, experiments, and finished media.
- [Projects](https://hob.farm/projects/) follow recurring characters, stories, tools, worlds, and formats.
- [Workshop](https://hob.farm/workshop/) shows how the work is made.
- [Academy](https://hob.farm/academy/) offers workflow education and structured learning paths.
- [Support](https://hob.farm/support/) collects ways to follow, share, collaborate, or help fund new work.

## On GitHub

This account holds the HobFarm website and selected tools used by the studio.

- [hobfarm](https://github.com/HobFarm/hobfarm) is the source for the website.
- [StyleFusion](https://github.com/HobFarm/StyleFusion) contains structured image-analysis and prompt tools.
- [hobbot](https://github.com/HobFarm/hobbot) collects automated creative and publishing experiments.

## Work on the site

The website is built with Astro and Tailwind CSS and deployed on Cloudflare Pages.

```bash
npm install
npm run dev
npm run build
```
