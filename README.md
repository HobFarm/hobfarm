# HobFarm

HobFarm is an independent publisher of articles, visual media, games, and creative systems.

The work ranges from reported features, satire, and archive research to recurring story worlds, browser experiments, production notes, courses, and physical or digital releases.

[Visit hob.farm](https://hob.farm)

## Published by HobFarm

- [Articles](https://hob.farm/articles/) are the editorial feed for features, arguments, research, satire, cartoons, and visual essays.
- [HobFarm Presents](https://hob.farm/departments/hobfarm-presents/) publishes recurring stories, characters, film and media series, and entertainment worlds.
- [Projects](https://hob.farm/projects/) collects games, creative applications, research tools, and experiments in development.
- [Gallery](https://hob.farm/gallery/) archives finished media, character systems, image sets, and visual studies.
- [Workshop](https://hob.farm/workshop/) documents how the work is made. [Academy](https://hob.farm/academy/) turns selected methods into practical one-time courses.
- [Shop](https://hob.farm/shop/) is the official directory for direct merchandise, character assets, craft packs, courses, and one-off physical finds.
- [Support](https://hob.farm/support/) explains how Ko-fi contributions and the monthly HobFarm Club help pay for the next round of work.

## On GitHub

This account holds the HobFarm website and selected software used by the publisher.

- [hobfarm](https://github.com/HobFarm/hobfarm) is the source for the website.
- [StyleFusion](https://github.com/HobFarm/StyleFusion) contains structured image-analysis and prompt tools.
- [hobbot](https://github.com/HobFarm/hobbot) contains the knowledge and publishing system behind several HobFarm projects.

## Work on the site

The website is built with Astro and Tailwind CSS and deployed on Cloudflare Pages.

```bash
npm install
npm run dev
npm run build
```
