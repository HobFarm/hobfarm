## Grimoire knowledge base and chatbot

The Grimoire knowledge graph is now accessible through the website. The knowledge base organizes visual atoms, creative techniques, and pipeline documentation into a browsable, interlinked reference.

### What shipped

- Knowledge base with entries organized by category (getting started, guides, reference, examples, recipes)
- Grimoire chatbot with SSE streaming via Cloudflare Workers
- Visual atom documentation (color, texture, lighting, composition, style families)
- Cross-linked entries with related article suggestions
- Difficulty-tagged content for beginner through advanced users
