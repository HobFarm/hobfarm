## Public gallery goes live

The gallery section launched as a public showcase for StyleFusion outputs. Each gallery entry displays the generated artwork alongside the style parameters and prompt details used to create it.

### What shipped

- Gallery index with filterable grid layout
- Individual gallery detail pages with full metadata
- Prompt export functionality (copy compiled prompts for external use)
- Tab switcher for viewing prompt components, generation parameters, and model details
- Support for multiple image formats per entry (comparison views across styles)
