XKXXKX treats interactive fiction the way roguelikes treat level design: every run is disposable, but the system that generates them is permanent.

The engine combines tabletop RPG mechanics with generative AI to produce stories that feel authored but are actually emergent. The Grimoire provides the vocabulary. The player provides the intent. Everything else is procedural.
