**Cute and Corrupted Cakes** starts with cake01 as the anchor pair: a polished two-tier pastel celebration cake, then the same cake rebuilt as a candlelit gothic centerpiece. The set now expands into red, orange, yellow, green, blue, and purple cake pairs, each with a cute still, a corrupted still, and a short transition video.

## Cute Version

The cute versions treat each cake like a professional product photo: clear tiers, clean frosting, strong color design, themed decorations, and readable bakery-display staging.

## Corrupted Version

The corrupted versions keep the cake recognizable while flipping the mood into a darker bakery fantasy. Clean frosting, bright color, and polished display cues become darker icing, heavier materials, haunted props, and corrupted lighting.

## Transformation Logic

Cute and Corrupted Cakes is not a different dessert. The goal is to keep the same-cake read while changing the frosting, palette, lighting, and setting. The tiers, toppers, piping, color identity, and display staging stay locked enough that the corrupted version still reads as the same cake.

## Gallery Assets

The free gallery shows web-size versions of each cute/corrupted pair plus the transition videos. Each video uses the matching cute still as its poster image, so the clean version is the first read before the transformation.
