# HobFarm New Wave Mesh Codex Build Pack

This package is the editorial and implementation handoff for a multimedia HobFarm article built from Paul Reubens's New Wave speech in *Cheech & Chong's Nice Dreams*.

Start with:

`CODEX_TASK.md`

Package contents:

```text
CODEX_TASK.md
editorial/
  ARTICLE_PACKET.md
  VISUAL_PLAN.md
research/
  USER_SOURCE_MATERIAL.md
data/
  asset-manifest.json
  network-edges-starter.csv
  rights-ledger-starter.csv
  source-ledger-starter.csv
  timeline-starter.json
  track-ledger.json
references/
  nice-dreams-new-wave-scene.png
  new-wave-mesh-original-concept.jpeg
```

The article is intentionally not a definitive history, ranking, or complete taxonomy of New Wave. It begins with one funny scene, then follows a selected set of documented connections through Brian Eno, Giorgio Moroder, David Bowie, Robert Fripp, Talking Heads, Devo, XTC, Peter Gabriel, Japan, Oingo Boingo, Paul Reubens, Primus, Daft Punk, and adjacent post-punk, goth, synth-pop, New Romantic, and art-pop branches.

The two supplied images are source references:

- `nice-dreams-new-wave-scene.png` is a user-supplied screenshot from the restaurant scene.
- `new-wave-mesh-original-concept.jpeg` is the author's earlier attempt to compress the whole idea into one infographic.

Preserve both originals. The old infographic is a conceptual ancestor, not the required visual design for the new article.
