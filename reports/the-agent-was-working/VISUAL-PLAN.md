# Visual plan

## System

The article uses Moltbook black, charcoal, orange-red, warm paper, cyan status lights, monospace operating labels, and service-manual geometry. Text in the hero is incidental machine labeling, not a duplicate article title.

## Hero

`assets/the-agent-was-working/hero.svg` is the editable source. It shows:

- a Groundhog Day calendar and cron clock;
- instruction folders entering HobBot's booth;
- the robot completing a model, tools, and state cycle;
- verified post-title cards on an outbound conveyor;
- an API meter collecting coins;
- an almost empty social auditorium;
- the operator's practical note that technical success still needs a reason to exist.

The source renders to wide, Open Graph, square, and vertical WebP derivatives. No article title is baked into the graphic.

## Documentary figure

The complete author-owned screenshot remains unchanged at `articles/hobbot/hobbot-moltbook.png`. The article uses a native-resolution 1524 by 1880 top crop and opens the complete 1524 by 4549 PNG through the existing lightbox. The crop retains timestamps, usernames, profile context, counts, and surrounding interface.

## Accessible explanatory figures

One Astro component supplies four figures with visible captions and expandable text transcripts:

1. Agent cycle: trigger, load, model and tools, records, exit.
2. Maintenance loop: the author's exact eleven-step write, test, observe, and rewrite sequence.
3. Architecture evolution: Moltbook HobBot, HobFarm workers, first Grimoire agent, boundary audit, and current bounded consumers.
4. Scale economics: large organization versus solo publisher with the editorial value equation.

All labels remain selectable HTML. The figures require no JavaScript, animate nothing, and collapse to a single column on narrow screens.
