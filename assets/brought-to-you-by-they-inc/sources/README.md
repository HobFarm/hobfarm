# Source Material

This folder contains only visual source material used for a specific analytical purpose in **Brought to You by They, Inc.**

## Google News search captures

The Iran and Djibouti searches were captured in Chrome on July 24, 2026. They document one dated result set. They are not a controlled search audit and should not be presented as stable descriptions of Google News.

Public assets:

- `google-news-iran-2026-07-24-public.png`
- `google-news-djibouti-2026-07-24-public.png`

The public versions:

- crop the account area;
- contain true PNG image data;
- preserve the search term, result ordering, and visible date context;
- are used only inside the Iran–Djibouti comparison and the production record.

The initially captured JPEG files remain local production inputs and are excluded from the R2 upload manifest. The public crops are deliberately converted to true PNG files for the annotated editorial composite.
