This directory holds the current character, wardrobe, pose, production, and Workshop sources used by the website expansion.

The seven system files and prose guide are exact current copies from the HobFarm character project material as of 2026-07-12. No equivalent legacy studio-automation or tool-capability-routing source documents were found, so neither was reconstructed. The wardrobe test remains a draft reference and does not establish public character canon.
