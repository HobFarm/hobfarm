## Lesson outline

1. Define the shared base.
2. Establish the cute baseline.
3. Write the corruption rule.
4. Choose controlled palette, material, damage, expression, humor, environment, and motion changes.
5. Build the pair.
6. Check continuity.
7. Package a card, entry, product concept, or series proof.
