## Lesson outline

1. Audit the model's default answer.
2. Separate subject, style, composition, palette, material, and output roles.
3. Extract visible rules instead of relying on a style name.
4. Build the baseline.
5. Apply one controlled transformation.
6. Apply a second transformation without losing the base.
7. Compare failure and drift.
8. Write the reusable style system.
9. Package it for another character, scene, or provider.

## Media requirements

- visual rule card;
- baseline plus two controlled changes;
- one drift comparison;
