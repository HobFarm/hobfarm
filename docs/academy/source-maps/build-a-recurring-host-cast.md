This is an advanced follow-on to the Avatar Content System Starter Kit. The sources support durable identity records, role-specific looks, destination mapping, and media-registry reuse. It must not repeat beginner folder and first-script lessons.

## Lesson outline

1. Define the host group and shared production purpose.
2. Lock identity and role boundaries.
3. Build two role-specific looks.
4. Write the voice and motion brief.
5. Map each host to useful destinations.
6. Produce a short presenter clip.
7. Save a reusable media-registry entry.

## Media requirements

- host identity and role cards;
- two role-specific looks;
- voice/motion direction excerpt;
- presenter clip with poster, captions, transcript, and no autoplay;
- typed example media-registry entry;
- one continuity failure.
