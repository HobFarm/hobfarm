## Course claim supported by the sources

The course teaches one beginner-sized loop: capture an idea, create a starter source file, draft a short script, establish voice and avatar direction, save a master clip, publish a placement, and record what the next post should change.

It does not promise revenue, perfect lip sync, provider permanence, or a complete aesthetic-systems practice.
