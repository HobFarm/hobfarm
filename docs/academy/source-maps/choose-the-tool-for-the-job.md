# Choose the Tool for the Job source map

Status: planned free acquisition tool  
Updated: 2026-08-06

## Source boundary

- The task brief defines the output-first questions and forbids a universal provider ranking.
- `/workshop/` supplies HobFarm's public production categories and evidence routes.
- Existing Academy manifests supply the shared vocabulary for inputs, tools, external costs, continuity, privacy, and intended artifacts.

No provider comparison is yet source-backed well enough to publish as a recommendation. Every future provider fact needs its own visible verification date.

## Planned artifact

A small public worksheet that returns a route shape: chat interface, direct provider interface, API, hosted workflow, local node system, or a chain. It should show the constraints that caused the route without claiming one platform is universally best.
