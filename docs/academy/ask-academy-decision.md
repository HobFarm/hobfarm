# Ask the Academy decision

Status: disabled  
Reviewed: 2026-08-06

Ask the Academy is deferred in code through `academyFeatures.askAcademyEnabled = false`. The course corpus currently has one migrated paid course and one paid course awaiting operator review. There are no real learner questions showing that generative retrieval would solve a measured support problem.

The first release uses searchable FAQs, a private structured question report, Customer Help routing, and an aggregate unresolved-question view. This keeps course gaps visible without creating an ungrounded assistant or another provider cost.

Reconsider the feature only after two paid courses pass validation and real questions show repeated gaps. Before activation it still needs authenticated entitlement-scoped retrieval, exact lesson citations, a `not covered` response, per-user and per-IP limits, a cost ceiling and kill switch, privacy-aware retention, and support routing.
